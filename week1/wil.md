WEB의 세 가지 역할

1. 무엇이 있는지 HTML
Hyper Text Makeup Language
웹페이지에 "무엇이 있는지" 적는 언어
제목, 글, 이미지, 버튼이 있다는걸 브라우저에게 알려주는 역할
<button>heart</button>
<span>10</span>
HTML만 있으면 이쁘지는 않음.
2. 어떻게 보이는지 CSS
Cascading Style Sheets
색상, 크기, 간격, 위치 등
좀 더 이뻐짐.

\-----But, 위에 두 가지만 하면 아무 일도 안일어남..(존재만 할 뿐 동작은 X) 하트를 누르면 뭐 어쩌라고? -> 빨갛게 변하라고!---------

3. 어떻게 동작하는지 JS
웹 페이지의 변화와 동작을 만드는 역할.



크롬창 -> Ctrl+shift+i or F12 -> Console창에서 수정
찾아서 -> 바꿨다
JS는 어떻게 화면에서 찾았을까? 어떻게 알았을까?



DOM과 Event
DOM(Document Object Model)
document-body-div-h1, ul 이런식으로 문서를 트리 구조로 만듦.
JS는 DOM을 통해 웹페이지의 요소를 찾고 바꿀 수 있음.

실제 사용자가 클릭을 했을 때 JS가 반응하려면?

Event : 클릭, 입력, 스크롤와 같이 웹에서 일어나는 사용자들의 행동

사람이 행동(클릭) -> Event -> JS -> 화면 변화(하트가 빨갛게 바뀜)
